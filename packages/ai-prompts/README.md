# `@expenseflow/ai-prompts`

Prompt Registry package managing versioned system prompt templates for Ollama / Qwen2.5:14B inference tasks in ExpenseFlow AI.

## Included Prompt Templates
* `CATEGORIZER_PROMPT`: Categorizes transactions and suggests purpose summaries.
* `MERCHANT_MEMORY_PROMPT`: Extracts canonical merchant strings and alias mappings.
* `CHAT_ASSISTANT_PROMPT`: RAG context prompt for conversational financial assistant queries.
